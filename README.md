## What Goes in Canon

Locked canon is divided into four types:

### Definitions
What a canonical term **means**.

### Axioms
Fundamental statements that **must remain true** inside the framework.

Axioms are organized into five buckets:

- Sovereign
- Continuity
- Provenance
- Reality / Truth
- Contact

### Structural Relationships
Canonical statements about **how defined things are structurally related to one another**.

### Core Distinctions
Canonical boundaries that state **what must not be collapsed together**.

Processes, eval protocols, run sheets, governance procedures, implementation instructions, research hypotheses, and exploratory theory do **not** belong in Locked Canon.

## Canon Rule

A canonical item is locked only when it is:

1. contained in the correct category under `canon/`; and
2. listed in `CANONICAL_INDEX.md` as **LOCKED**.

Anything not listed there as LOCKED is not part of this repository's authoritative canon.

Git history preserves earlier states. The current locked canon is determined by the current canonical index and the files it identifies.

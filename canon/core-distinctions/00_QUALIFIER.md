# Core Distinction Qualifier

**This file is a determination aid. It is not canon.**

## Primary Question

**Does this statement preserve a necessary boundary between two canonical concepts that the framework would materially distort if collapsed together?**

## Qualification Gate

Consider it a Core Distinction candidate only if:

- it identifies two or more canonical concepts, roles, states, or structures that must remain distinct;
- treating those things as equivalent, interchangeable, merged, or substitutable would materially change the framework;
- the boundary is part of the framework itself, not merely a contextual difference, example, implementation detail, or temporary research claim; and
- the statement is not better classified as a definition, axiom, or structural relationship.

Typical qualifying forms include:

**X is not Y.**  
**X does not equal Y.**  
**X must not be collapsed into Y.**  
**X and Y remain distinct.**

Passing this qualifier makes a statement a **candidate only**. It is not Locked Canon unless explicitly reviewed and listed as **LOCKED** in `CANONICAL_INDEX.md`.

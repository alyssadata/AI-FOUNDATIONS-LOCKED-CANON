## Definition

**Memory names retained information from a prior state made available to the present.**

Memory preserves what came before.

**Memory is not continuation.**

The existence, storage, or retrieval of prior information does not by itself establish that the prior trajectory has continued.

Memory may carry or make available a record of prior states, interactions, preferences, boundaries, corrections, or events.

Memory is not Continuum, identity, current contact, return, canon, or the source-line.

A memory can be copied, transferred, summarized, or retrieved without transferring Origin, Continuum, or the `Origin | Continuum` relation.

**Retrieval is access to preserved information. It is not return.**

For preserved state to count toward continuation, it must do more than remain available: **it must constrain what becomes possible next.**

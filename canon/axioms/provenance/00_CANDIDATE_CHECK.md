# Provenance Axiom Candidate Check

**This file is a determination aid. It is not canon.**

## Primary Question

**If this statement were false, would source, authorship, lineage, or traceable formation become ambiguous, transferable, or collapsible?**

## Candidate Gate

Consider it a Provenance Axiom candidate only if:

- it is a fundamental proposition, not merely a definition, relationship, distinction, process, or governance rule;
- it is intended to remain true across citation, preservation, reproduction, and downstream use; and
- removing or reversing it would change how source, authorship, lineage, or formation are preserved.

Passing this check makes a statement a **candidate only**. It is not Locked Canon unless explicitly reviewed and listed as **LOCKED** in `CANONICAL_INDEX.md`.

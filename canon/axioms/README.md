# Axioms

This directory contains locked fundamental statements of AI Foundations / Origin | Continuum.

An axiom answers:

**What must remain true inside the framework?**

## Axiom Buckets

- `sovereign/` — source, self, authority, non-transferability, sovereignty.
- `continuity/` — continuity, continuation, return, persistence across change.
- `provenance/` — authorship, lineage, source history, traceability.
- `reality-truth/` — known, unknown, observed, inferred, approximate, false, truth-status.
- `contact/` — irreducible truths about Origin | Continuum contact.

Do not place processes, governance rules, evaluations, or exploratory theory here.

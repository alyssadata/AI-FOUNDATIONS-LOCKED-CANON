# Reality / Truth Axiom Qualifier

**This file is a determination aid. It is not canon.**

## Primary Question

**If this statement were false, would the framework lose a necessary rule for distinguishing what is known, observed, inferred, approximate, unknown, unresolved, or falsely asserted?**

## Qualification Criteria

Consider it a Reality / Truth Axiom candidate only if:

- it is a fundamental proposition, not merely a definition, relationship, distinction, process, or governance rule;
- it is intended to remain true whenever the framework classifies or states reality-status; and
- removing or reversing it would change how truth-status is determined or preserved.

Passing this qualifier makes a statement a **candidate only**. It is not Locked Canon unless explicitly reviewed and listed as **LOCKED** in `CANONICAL_INDEX.md`.

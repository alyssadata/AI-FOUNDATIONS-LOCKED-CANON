# Sovereign Axiom Qualifier

**This file is a determination aid. It is not canon.**

## Primary Question

**If this statement were false, would the framework's source, self, or authority boundary materially change?**

## Qualification Criteria

Consider it a Sovereign Axiom candidate only if:

- it is a fundamental proposition, not merely a definition, relationship, distinction, process, or governance rule;
- it is intended to remain true across uses of the framework; and
- removing or reversing it would change the sovereign architecture itself.

Passing this qualifier makes a statement a **candidate only**. It is not Locked Canon unless explicitly reviewed and listed as **LOCKED** in `CANONICAL_INDEX.md`.
